# Генераторы сборников «Три пути»

Исходники трёх PDF из подарка подписчикам (Frederick, `backend/assets/gifts/`)
и игры `/igry/tri-puti.html`. Раньше жили только в песочнице ассистента —
после её очистки новую редакцию было бы не из чего собрать.

- `chisla.py`, `predmety.py`, `karta.py` — банки заданий этапов I–IV
  (числа, предметы и ситуации, карты местности). Каждый при импорте
  печатает свой лист и пишет `<имя>.html` рядом с собой.
- `kursant2.py` — базовый сборник, редакция 1: легенда курсанта 19 лет
  (Подмосковье, колледж, бокс, мотоцикл). Отбор десяти заданий на этап,
  оформление, этапы V–VI, ведомость. Пишет `kursant.html`.
- `kursant_g.py` — редакция 2, легенда курсантки 19 лет. Пишет `kursant_g.html`.
- `kursant_30.py` — редакция 3, легенда курсанта 34 лет (инженер-сметчик,
  ипотека, двое детей, хоккей, гараж). В этапе II четыре школьных задания
  заменены на взрослые. Пишет `kursant_30.html`.
- `poryadok.py` — сборник «Порядок» (тема 6, после «Трёх путей» и «Выбора пути»):
  восемь этапов от 0 «Обратные операции» (уравнения раскруткой с конца) до
  VII «Длинная цель». Берёт легенду из `kursant2.py` и карты из `karta.py`,
  этап «Числовое поле» генерирует сам (`random.seed(11)`, ключи считаются
  кодом). Пишет `poryadok.html`, рендер — `poryadok_pdf.js` → `poryadok-kursant.pdf`.
- `traektoriya.py` — сборник «Траектория» (тема 7): навык видеть, куда ведёт
  линия — правило по точкам, тип хода, порог и дата, звено поворота, коридор.
  Восемь этапов от рядов (6, 9, …) до десяти лет и журнала прогнозов; графики
  этапа II рисуются SVG. Спецификация — `TRAEKTORIYA-SPEC.md`. Пишет
  `traektoriya.html`, рендер — `traektoriya_pdf.js` → `traektoriya-kursant.pdf`.
- `*_pdf.js` — рендер HTML в PDF через Playwright (Chromium из `/opt/pw-browsers`).

Сборка одной редакции:

```bash
python3 tools/tri-puti/kursant_30.py && node tools/tri-puti/kursant_30_pdf.js
```

Результат — `tools/tri-puti/tri-puti-kursant-30.pdf`, 25 страниц А4. HTML и PDF
здесь не хранятся (`.gitignore`); готовые PDF лежат в Frederick.

Правила текста те же, что у сайта: без придуманных фамилий, кавычки «ёлочки»,
цены руками не вписывать. Легенда — это постоянные ресурсы курсанта: в «Дано»
они не повторяются, но участвуют в каждом задании.
