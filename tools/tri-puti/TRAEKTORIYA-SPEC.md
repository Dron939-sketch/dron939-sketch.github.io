# Тема 7 «Траектория» — спецификация навыка (27.09.2026)

Линейка: тема 4 «Три пути» (обход), 5 «Выбор пути» (критерий), 6 «Порядок» (цепочка назад), 7 «Траектория» (куда ведёт линия).

## 1.1 Отрабатываемый навык
По нескольким точкам (числа, события, решения) за нормативное время: назвать правило, которое их порождает, и сколько точек его подтверждают; назвать тип хода (ровный, ускоряющийся, с насыщением, качели, шум); продолжить на N шагов и назвать дату, когда линия пересечёт порог; назвать одно звено правила, изменение которого поворачивает линию; сказать «точек мало», когда их мало. Сухая формулировка: по прошлому назвать будущее и точку, где его можно повернуть.

## Операции (ТОТЕ)
0. Точки: три-пять последних состояний с датами.
1. Правило: разность / отношение / повтор → тип хода.
2. Проверка: сколько точек согласны, есть ли выброс.
3. Продолжение: N шагов, порог, дата.
4. Поворот: какое звено правила менять.
5. Честность: коридор ответа, «мало точек».
Выход: прогноз записан с датой; когда дата пришла — сверка с фактом (журнал прогнозов). Признак сформированности: калибровка — попадает в той доле, в какой обещал.

Образец для 0-01: 6, 9, … → 12 (+3), 13,5 (×1,5), 15 (сумма предыдущих) — двух точек мало, нужна третья.

## Лестница
0 Ряды — арифм., геом., Фибоначчи, квадраты, чередование, выброс, два правила, две точки. Новое: правило + число точек, «мало точек».
I Таблица по датам — вес, остаток на карте, страницы, км. Новое: дата порога.
II Кривые — линия, экспонента, S-кривая, качели, шум. Новое: тип по форме, насыщение.
III Процессы — сложный процент, долг, остывание, привычка с пропусками, форма к турниру, плато в учёбе. Новое: правило от физики, поворот одним звеном.
IV Люди — три случая → правило → прогноз четвёртого (начальник, друг, партнёр).
V Своя жизнь (легенда) — доход, учёба, бокс, отношения; «если ничего не менять, через год и три».
VI Решения — две линии от одного выбора, точка невозврата, где расходятся.
VII Десять лет — связка с «Дело жизни» Л1 и «Своя колея»; одно правило, меняющее всё; журнал прогнозов на месяц.

## Ошибки, встроить в задания
Линейное продолжение экспоненты; ошибка игрока и горячая рука; лучший результат вместо возврата к среднему; закономерность в трёх случайных точках; игнор насыщения; оптимизм по срокам; «в этот раз иначе».
