# meysternlp.ru — сайт психолога Андрея Мейстера

Статический сайт (GitHub Pages → Amvera). Бэкенд приложения «Фреди» — отдельный
репозиторий `Dron939-sketch/Frederick` (FastAPI, https://ffred-ddd989.amvera.io).

## Карта

- `/blog/` — блог (445+ статей). Статьи генерируются скриптами
  (`genblog.py` + `articles_data.py`; индекс — `genblog2.py`).
  Источник истины по рубрикам и статьям — `blog/blogmap.json` (в репо),
  полнотекстовый поиск — `blog/search-index.json`.
- `/blog/lektorij/` — Лекторий: каталог направлений («университет жизни»).
  Страницы курсов — `/blog/lektorij/<kurs>/`. Лекции — обычные статьи блога
  `blog/lekciya-*.html`, рубрика `lektorij`.
- `/fredi/` — веб-приложение «Фреди» (ИИ-психолог).
- `header.html` / `footer.html` — общие; ряд страниц несёт встроенную копию
  навигации — при изменении меню обновлять все вхождения.

## Правила

- **Лекции пишутся строго по методичке** `blog/lektorij/METODICHKA.md`:
  цель — понимание, схемы со «голосовыми» подписями (figcaption читается
  Фреди), структура, чек-лист. Прочитай её перед написанием лекции.
- Озвучка статей — серверная (Frederick, `backend/blog_tts_routes.py`):
  mp3 кэшируется навсегда, figcaption схем попадает в озвучку как
  «взгляните на схему…».
- После правок проверять рендер локально: `python3 -m http.server 8099`
  из корня + Playwright-скриншот.
- Новая статья = обновить hub/рубрику, blogmap, search-index, sitemap.xml.
