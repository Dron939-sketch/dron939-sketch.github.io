# Video Analyzer для импринт-видеорядов

Инструмент анализа видео для методики «25 кадр Мейстера». Извлекает кадры и звуковые акценты, чтобы их можно было обсудить со специалистом.

## Зачем

В облачном окружении Claude видеоплатформы заблокированы (политика безопасности). Этот скрипт нужно запустить **локально** у себя на компьютере — он скачает видео, разберёт его на кадры и звуковую разметку, после чего получившиеся файлы можно передать в чат для анализа.

## Что делает

1. Скачивает видео по URL (YouTube, VK, RuTube, прямые ссылки) — через yt-dlp.
2. Извлекает метаданные (длительность, fps, разрешение).
3. Извлекает кадры с заданным интервалом (по умолчанию 0.5 сек).
4. Извлекает звук и находит пики амплитуды (звуковые акценты).
5. Создаёт текстовый отчёт `report.md` с временными метками кадров и звуковых якорей.
6. Сохраняет всё в `output/<имя>/`.

## Установка

```bash
# Любая ОС с Python 3.9+
pip install yt-dlp imageio-ffmpeg numpy
```

ffmpeg либо системный (если установлен), либо подтягивается через `imageio-ffmpeg`.

## Использование

```bash
# По URL
python video_analyzer.py "https://vkvideo.ru/video-234137703_456239019"

# По локальному файлу
python video_analyzer.py /path/to/video.mp4

# С другими параметрами
python video_analyzer.py "URL" --interval 0.3 --peak-threshold 0.6
```

### Параметры

- `--interval` — интервал извлечения кадров в секундах. По умолчанию **0.5**. Для коротких импринт-видеорядов (20–35 сек) можно поставить **0.3**, чтобы получить плотнее. Для длинных (>2 мин) — **1.0**, чтобы не утонуть в кадрах.
- `--peak-threshold` — порог звукового пика (0..1). По умолчанию **0.7**. Если детектируется слишком много шумных пиков — поднимите до **0.8**. Если слишком мало — опустите до **0.5**.
- `--output-dir` — папка результатов. По умолчанию `./output/`.

## Результат

В папке `output/<имя_видео>/`:

- `source.mp4` — само видео
- `frames/` — папка с кадрами (frame_0001.jpg, frame_0002.jpg, ...)
- `report.md` — главный отчёт (читать первым)
- `report.json` — машиночитаемая версия

## Что передавать в чат

1. **report.md** — целиком (текст).
2. **3–5 ключевых кадров** из `frames/`:
   - Первый кадр (часто это «результат» — кадр желания).
   - Последний кадр (часто это «результат после пути»).
   - Кадры рядом со звуковыми пиками (см. таблицу в report.md).

Этого достаточно, чтобы я (или другой специалист) проанализировал видеоряд по методике «25 кадра Мейстера» и сказал:
- какие эмоции маркированы звуком;
- правильно ли выстроен Ид→Эго→Ид;
- какие моменты усилены, какие — нет;
- что можно изменить.

## Если что-то не работает

**Ошибка SSL/сертификат при скачивании**: установите свежий yt-dlp:
```bash
pip install -U yt-dlp
```

**VK даёт 403**: видео может быть приватным. Попробуйте через браузер с расширением «Video DownloadHelper» и сохраните локально, затем запустите скрипт по пути к файлу.

**ffmpeg не найден**:
```bash
pip install imageio-ffmpeg
```

**Слишком много кадров (сотни)**: поднимите `--interval` до 1.0 или 2.0.

**Не находит звуковые пики**: опустите `--peak-threshold` до 0.5.
